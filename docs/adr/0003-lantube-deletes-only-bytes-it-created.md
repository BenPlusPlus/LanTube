# LanTube deletes only bytes it created

Deleting an uploaded Video removes the catalogue row and the file (and poster) LanTube wrote on the Media share. Dropping an indexed Folder Video from the catalogue, including on rescan, never deletes the house’s file on the array. A missing file at watch time stays an honest player error until a rescan reconciles the catalogue. Making the catalogue and disk always match, including unlinking NAS files from the UI, was rejected because one click would destroy the family archive.
