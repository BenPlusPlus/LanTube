# Assigned play gate binds the signed-in Person only

While a limitable Person has unfinished Assignments, they cannot play a non-assigned Video: Watch, media, search, channels, playlists, and pasted URLs all refuse that play. The gate is that signed-in Person’s, not the house’s. Unsigned watch stays the Admin house setting; auto-disabling it because one Person has homework would lock the whole LAN. Direct files on the Media share stay out of scope.
