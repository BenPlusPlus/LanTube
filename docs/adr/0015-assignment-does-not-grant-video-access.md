# Assignment does not grant Video access

An Assignment is a duty to watch a Video the Person can already see. A Parent may only assign a Video that Person can already `canWatch`; naming them on Audience (or making the Video house-visible) is how sight is granted. The other path is “assigning a private Video lets them watch it,” which would make Assignment a second Audience and would leak private library the same way playlist membership would. Each Video keeps its own Audience, Channel owner, Managers, and Parent rules (ADR-0010).
