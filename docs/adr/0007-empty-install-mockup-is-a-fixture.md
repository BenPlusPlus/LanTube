# Empty install; the mockup house is a fixture

A production catalogue starts empty: no People, Videos, or Folders until someone on the LAN joins and an Admin attaches a Folder. The first Person is an Admin and may also take Parent on that join. The mockup household (Mia, Leo, Tahoe, …) is a test/dev fixture, not a migration. Seeding demo People into a real house would put fictional logins and channels on the LAN.
